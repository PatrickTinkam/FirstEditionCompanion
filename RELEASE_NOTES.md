# First Edition Companion v0.5.0

This release replaces the original free-form Gear page with a structured AD&D 1st Edition inventory and equipment system.

## Highlights
- Added a dedicated **Equipped** section with equipment slots such as main hand, off hand/shield, armor, head, neck, cloak, hands, waist, feet, rings, missile weapon, and ammunition.
- Added separate **Carried Gear**, **Magic Items**, **Valuables & Treasure**, and **Mounts, Tack & Transport** sections.
- Added searchable equipment catalogs using core **Players Handbook**, **Dungeon Masters Guide**, and **Unearthed Arcana** material with source-book labels.
- Added a large searchable DMG/UA magic-item catalog organized into potions/oils/elixirs, scrolls, rings, rods/staves, wands, miscellaneous magic, magic armor/shields, magic swords, other magic weapons, and artifacts/relics.
- Added item quantity, equipped state, equipment slot, optional charge/use tracking, and personal notes.
- A magic item can appear in both **Equipped** and **Magic Items** while remaining one underlying inventory record.
- Added an organized **Currency** section for copper, silver, electrum, gold, and platinum pieces using the PHB monetary system, including total value in gold-piece equivalents.
- Added **Valuables & Treasure** catalog entries for gems, jewelry, art objects, rare books/manuscripts, and precious-metal treasure.
- Added **Mounts, Tack & Transport** catalog entries for animals, saddles/barding, carts, wagons, boats, galleys, merchant ships, and warships.
- Preserved the old free-form gear field as **Legacy Gear Notes** so upgrading does not discard existing equipment notes.
- New structured inventory and currency data are included automatically in character profiles and v0.4+ portable JSON backups.

## Catalog scope
The built-in catalog intentionally focuses on the core AD&D 1e hardcover rules used by this app: PHB, DMG, and Unearthed Arcana. It does not silently mix Dragon magazine equipment into the core lists. Item names, categories, source labels, and concise reference data are included; long copyrighted rulebook descriptions are not reproduced. Consult the named source for exact special powers, restrictions, command words, charge rules, and other detailed text.

## Updating
v0.5.0 uses the same stable prototype signing key introduced in v0.4.0, so it should install directly over v0.4.0 and preserve local app data. **Export Saves** before updating is still recommended as a safety backup.

## Installation
Download the attached `FirstEditionCompanion-v0.5.0.apk` from this release and install it on Android.
