# First Edition Companion v0.7.1

v0.7.1 fixes the remaining gear/treasure description gap discovered during v0.7.0 testing.

## Fixes
- Fixed nonmagical DMG and UA catalog entries falling back to the obsolete “source PDF required” message.
- Every built-in gear and treasure entry now routes through an offline native description path.
- Added dedicated DMG-based summaries for gem value categories, jewelry valuation, art objects, rare books/manuscripts, precious-metal treasure, elfin chain, helms, and spellbooks.
- Added category-level native handling for weapons, armor, shields, adventuring gear, religious items, provisions, animals, tack/harness, transport, clothing, herbs, writing supplies, and valuables.
- Art Object now correctly explains that it is a nonmagical treasure-tracking category with DM/appraised value rather than a magic item with a missing source PDF.
- Magic-item behavior from v0.7.0 remains intact.

## Source integrity
The supplied Players Handbook and Dungeon Masters Guide remain the verified 1e source base. UA-only material remains explicitly treated as supplied-variant content where the provided UA file uses later/conversion-style mechanics.

Descriptions are paraphrased table-use summaries; source PDFs remain optional verification tools rather than app dependencies.

## Updating
v0.7.1 uses the same stable prototype signing key and should install directly over v0.7.0 while preserving local data. Export Saves before major updates is still recommended.

## Installation
Download the attached `FirstEditionCompanion-v0.7.1.apk` and install it on Android.
